# 01. 개요

## 무엇을 만드는가

**clip-ferry**는 한 사람이 가진 여러 기기(Windows, macOS, Android, iOS) 사이에서 클립보드의 **텍스트와 이미지**를 주고받게 해주는 서비스다.

- 기기들이 **서로 다른 네트워크**에 있어도 동작한다 (집 PC ↔ LTE 폰).
- 내용은 기기에서 암호화되고 기기에서만 복호화된다 (**종단간 암호화**).
- 서버는 암호문을 실시간으로 넘겨주기만 하고 **아무것도 저장하지 않는다.**
- 한 사용자가 **여러 대의 기기**를 하나의 그룹으로 묶어 관리한다. 사용자 수가 늘어나도 서버를 수평 확장할 수 있어야 한다.

## 원칙 (모든 설계 판단의 기준)

1. **서버는 멍청하게.** 서버는 "채널에 들어온 바이트를 같은 채널의 다른 연결로 넘긴다"만 한다. 기기 추가·제거, 키 관리, 권한 판단은 전부 기기(코어)가 한다.
2. **서버 무저장.** 메시지 내용·전송 내역을 디스크에도, 메모리 큐에도 보관하지 않는다. 받을 기기가 없으면 버린다(푸시로 깨우는 것은 예외적 경로이며 그것도 저장이 아니다).
3. **계정 없음.** 이메일·비밀번호 로그인이 없다. 그룹은 기기들이 공유하는 비밀(그룹 키)로만 존재한다. 서버에 개인정보가 쌓일 곳이 없어야 한다.
4. **새 기기는 기존 기기의 승인으로만.** 서버나 제3자가 기기를 그룹에 넣을 수 없다.
5. **암호 코드는 한 벌.** 암호화·프로토콜 로직은 Rust 코어 하나에만 있고 모든 플랫폼이 그것을 쓴다.
6. **플랫폼 제약을 받아들인다.** OS가 막는 것을 꼼수로 뚫지 않는다. 대신 가장 적은 탭으로 되게 만든다.
7. **정직한 표현.** "서버는 내용과 내역을 저장하지 않는다"까지만 주장한다. 서버는 IP·접속 시각·데이터 크기는 볼 수 있다.

## 플랫폼별 목표 동작

| 플랫폼 | 다른 기기 → 이 기기 | 이 기기 → 다른 기기 |
|---|---|---|
| Windows | 자동 (클립보드에 바로 들어감) | 자동 (복사하면 바로 전송) |
| macOS | 자동 | 자동 (changeCount 폴링) |
| Android | 자동 (앱 연결 중) / 푸시로 깨움 | 복사 후 **빠른 설정 타일·알림 버튼 1탭**, 또는 공유 메뉴·텍스트 선택 메뉴 |
| iOS | 앱이 열려 있으면 자동, 아니면 **푸시 알림 탭** → 클립보드에 들어감 | 복사 후 **단축어·뒷면 탭·제어 센터 버튼 1탭**, 또는 공유 확장 |

## 범위 밖 (v1에서 하지 않음)

- 계정/로그인, 웹 클라이언트, Linux 클라이언트
- 서버 측 클립보드 히스토리, 클라우드 백업
- 다른 사람과 공유(가족·팀 그룹)
- 파일(문서 등) 전송 — 이미지 외 파일은 v1 범위 밖
- 모든 기기를 잃어버렸을 때의 복구 (새 그룹을 만들면 된다. 잃을 데이터가 없다)

## 용어

| 용어 | 뜻 |
|---|---|
| 기기(device) | 앱이 설치된 하나의 단말. 자기 키 쌍(서명용 Ed25519, 키 교환용 X25519)을 가진다 |
| 그룹(group) | 한 사용자의 기기 묶음. 그룹 키를 공유한다 |
| 그룹 키 | 그룹 구성원만 아는 32바이트 비밀. 여기서 내용 암호화 키와 채널 ID가 파생된다 |
| 에포크(epoch) | 그룹 키의 세대 번호. 기기 제거 시 키를 회전하면 1 증가 |
| 로스터(roster) | 그룹 구성원 목록 (기기 ID, 공개키, 이름, 푸시 토큰). 기기들끼리 암호화해서 동기화한다 |
| 채널 ID | 릴레이가 라우팅에 쓰는 32바이트 값. 그룹 키에서 파생되므로 알면 곧 그 그룹 구성원이라는 뜻(구성원이 아니면 추측 불가) |
| 디바이스 태그 | 릴레이에게 보이는 기기 식별자. 그룹 키와 기기 ID에서 파생되어 에포크마다 바뀐다 |
| 초대(invite) | 새 기기를 그룹에 넣기 위해 기존 기기가 만드는 일회용 비밀. QR 또는 텍스트 코드로 전달 |
| SAS | Short Authentication String. 페어링 중 양쪽 화면에 같은 6자리 숫자가 뜨는지 사용자가 눈으로 확인 |
| 코어(core) | 모든 플랫폼이 공유하는 Rust 라이브러리 |
| 셸(shell) | 플랫폼별 앱. 클립보드·UI·OS 연동만 담당 |
| 릴레이(relay) | 중계 서버 |
