# clip-ferry 개인정보처리방침 (초안)

> **초안이다(F39).** 공개 배포(F40) 전에 운영 주체·문의처·시행일·서버 위치를 채우고 공개 URL에 게시한다.
> `<…>`로 표시한 곳이 채울 자리다. 내용이 코드와 달라지면 이 문서를 먼저 고친다.

시행일: `<YYYY-MM-DD>`
운영 주체: `<이름 또는 상호>`
문의: `<문의 이메일>`

clip-ferry(이하 "서비스")는 내 기기들 사이에서 클립보드(글·이미지)를 주고받는 앱입니다. 이 문서는 서비스가 어떤 정보를 왜 수집하고, 얼마나 보관하며, 어떻게 지울 수 있는지 설명합니다.

## 1. 한눈에 보기

- **클립보드 내용은 서버가 볼 수 없습니다.** 내용은 보내는 기기에서 암호화되어 내 다른 기기에서만 풀립니다(종단간 암호화). 암호를 푸는 열쇠는 내 기기에만 있고 서버에는 없습니다. 서버는 암호화된 내용을 전달만 하고 저장하지 않습니다.
- 서버가 저장하는 것은 **로그인한 계정 정보, 계정에 연결된 기기 목록, 날짜별 사용량(횟수·크기)** 뿐입니다.
- 홈페이지의 **계정 삭제** 페이지에서 언제든 바로 지울 수 있습니다.

## 2. 수집하는 정보와 목적

| 정보 | 언제 | 목적 | 보관 |
|---|---|---|---|
| 구글 계정 식별자(`sub`), 이메일, 이름, 프로필 사진 주소 | 구글로 로그인할 때 구글이 알려 준다 | 계정을 구별하고, 같은 계정의 기기끼리 연결하고, 앱에 누구로 로그인했는지 보여 주기 위해 | 계정을 삭제할 때까지 |
| 가입 시각, 마지막 로그인 시각 | 로그인할 때 | 계정 관리, 서비스 운영 통계 | 계정을 삭제할 때까지 |
| 기기 식별자(무작위 값), 기기 이름, 플랫폼(Windows·macOS·Linux·Android·iOS), 등록 시각, 마지막 접속 시각 | 앱이 서버에 연결할 때 | 내 기기 목록을 보여 주고, 서비스 운영 통계 | 계정을 삭제할 때까지 |
| 날짜별 전송 횟수와 전송한 데이터 크기(바이트) | 기기가 내용을 보낼 때 릴레이가 센다 | 남용 방지, 사용량 제한·요금제의 기초, 운영 통계 | **13개월** 뒤 자동 삭제, 계정 삭제 시 즉시 삭제 |
| 로그인 유지용 토큰(서버에는 해시값만) | 로그인할 때 | 다시 로그인하지 않아도 되도록 | 최대 30일(사용할 때마다 새로 바뀜), 로그아웃·계정 삭제 시 무효 |

**수집하지 않는 것**: 클립보드 내용과 내역, 암호화 열쇠(그룹 키·기기 개인키), 연락처·위치·사진첩, 광고 식별자. 클립보드 내용은 위 1절처럼 서버가 볼 수 없는 형태로만 지나갑니다.

**IP 주소**: 기기가 서버에 연결하면 서버는 통신을 위해 IP 주소를 알게 됩니다. 연결 수 제한(남용 방지)에 연결 중에만 쓰고, 저장하거나 로그에 남기지 않습니다.

## 3. 제3자 제공·처리 위탁

- 정보를 팔거나 광고에 쓰지 않습니다.
- **Google**: 구글 로그인에 씁니다. 로그인 과정은 Google의 개인정보처리방침을 따릅니다.
- **서버 운영**: `<호스팅 업체·국가>`의 서버에서 운영합니다. (F40에서 정한다. 개발 중에는 운영자의 장비에서 운영한다.)
- 법령에 따라 요구되는 경우를 빼고는 다른 곳에 제공하지 않습니다.

## 4. 운영자가 보는 정보

운영자는 서비스 운영을 위해 관리 페이지에서 가입자 수, 활성 사용자 수, 플랫폼별 기기 수, 날짜별 사용량을 봅니다. 문의 처리·남용 대응을 위해 개별 계정의 이메일·이름·기기 목록·사용량을 볼 수 있습니다. 클립보드 내용은 운영자도 볼 수 없습니다(서버에 없습니다). 관리 페이지는 허용된 운영자 계정만 들어갈 수 있습니다.

## 5. 계정 삭제와 권리

- **홈페이지에서 삭제**: `<계정 삭제 페이지 URL — F40>`에서 구글로 로그인한 뒤 `계정 삭제`.
  - 서버에 있는 계정 정보, 기기 목록, 사용량, 로그인 토큰이 **즉시** 지워지며 되돌릴 수 없습니다.
  - 그 계정으로 로그인한 기기는 곧(최대 1시간 안에) 로그아웃됩니다.
  - 기기에 있는 그룹 정보(암호화 열쇠)는 서버에 없으므로 각 기기에 남습니다. 앱에서 그룹을 나가거나 앱을 지우면 없어집니다.
  - 같은 구글 계정으로 다시 로그인하면 새 계정으로 시작합니다.
- **홈페이지를 쓸 수 없을 때**: `<문의 이메일>`로 요청하면 확인 후 지웁니다.
- 내 정보 열람·정정·처리 정지를 요청할 수 있습니다. 문의처로 연락하세요.

## 6. 보안

- 클립보드 내용은 종단간 암호화합니다. 새 기기는 이미 그룹에 있는 기기의 사용자가 화면의 숫자를 비교해 승인해야만 들어올 수 있습니다.
- 서버와의 통신은 암호화된 연결(HTTPS·WSS)을 씁니다.
- 로그인 토큰은 서버에 원문이 아닌 해시값만 저장하고, 기기에서는 운영체제의 보안 저장소에 둡니다.
- 서버 로그에는 이메일과 토큰을 남기지 않습니다.
