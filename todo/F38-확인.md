상태: `완료` (PR #32) (docs/05-progress.md). 브랜치 `f38-operator-stats` (F37 완료 커밋 위).

## 무엇을 시험하나

- 계정 서버의 `/admin` 페이지에서 **허용 목록에 있는 구글 계정**으로 로그인하면 아래가 보인다.
  - 가입자 수, 오늘 활성(DAU), 30일 활성(MAU), 30일 전송 수·전송량
  - 플랫폼별 기기 수
  - 최근 30일 일별 표: 활성, 신규 가입, 전송, 바이트
  - 사용자 목록(검색)과 사용자 상세(계정 정보·기기·최근 90일 사용량)
- 허용 목록 밖 계정은 들어오지 못한다(403).
- 활성 = 그날 한 번이라도 전송한 계정. 날짜는 UTC 기준(D-023).
- 클립보드 내용은 서버에 없으므로 이 페이지에도 없다.

## 1. Pi: 허용 목록 넣고 계정 서버 다시 빌드

**Pi에서** (SSH). `<내 구글 이메일>`은 앱에 로그인하는 구글 계정 주소로 바꾼다:
```bash
cd ~/clip-ferry && git fetch && git checkout f38-operator-stats && git pull
grep -q '^CF_ADMIN_EMAILS=' deploy/.env.account || echo "CF_ADMIN_EMAILS=qkrwhdgur0319@gmail.com" >> deploy/.env.account
grep CF_ADMIN_EMAILS deploy/.env.account
docker compose --env-file deploy/.env.account -f deploy/compose.account.yml up -d --build
```
- [x] `grep` 결과가 `CF_ADMIN_EMAILS=…`이고, 그 주소가 내 구글 이메일이다
- 다시 빌드는 10~20분. **릴레이(`compose.yml`)는 다시 올리지 않는다.**

다 되면 (Pi에서):
```bash
docker compose --env-file deploy/.env.account -f deploy/compose.account.yml logs account | tail -5
curl -s -o /dev/null -w "%{http_code}\n" https://raspberry-pi.tailb6b7a3.ts.net:8443/admin
curl -s -o /dev/null -w "%{http_code}\n" https://raspberry-pi.tailb6b7a3.ts.net:8443/admin/api/stats
```
- [x] 로그에 `/admin enabled for 1 account(s)` (이메일은 로그에 남기지 않는다)
- [x] 첫 `curl`은 `200`(페이지), 두 번째는 `401`(로그인 없이는 통계를 주지 않는다)
- `404`면 예전 코드거나 `CF_ADMIN_EMAILS`가 비어 있다 → 위를 다시

## 시험 중 나온 것

1. (PR CI, `account (MariaDB)`) `admin_stats_users_and_detail`이 가입자 증가분 `5 != 2`로 실패. MariaDB 시험은 모든 테스트가 한 DB를 동시에 써서 다른 테스트가 만든 계정이 섞였다(질의는 맞음: DAU 1, 전송 5, 1024바이트). 전체 합계는 메모리 저장소에서만 정확히, MariaDB에서는 "적어도 그만큼 늘었다"로 확인하게 고침
2. (PR CI 다시) `google_login_me_and_devices`가 기기 등록에서 `500 internal`. 동시에 기기를 넣는 트랜잭션끼리 MariaDB 교착(1213/40001)으로 보인다(기존 코드의 경합, 통계 테스트가 기기를 더 넣으며 드러남. 운영에서도 날 수 있음) → 기기 등록·갱신 토큰 교체 트랜잭션을 교착 때 4번까지 다시 시도. 테스트 출력에 서버 로그(DB 오류 원문)도 나오게 함

## 알려진 사항

- 활성(DAU·MAU)은 전송 기준이다. 앱을 켜 두기만 하고 보내지 않은 계정은 활성이 아니다(D-023).
- `플랫폼별 기기`의 `등록`은 계정 서버에 등록된 적 있는 기기 수다. 그룹에서 지운 기기도 남는다(계정 삭제 F39 전까지). 실제로 쓰는 기기는 `최근 30일 접속`을 본다.
- 운영자 토큰은 1시간, 브라우저 탭을 닫으면 사라진다(sessionStorage). 앱·릴레이 접속 토큰과는 서로 쓸 수 없다.
