상태: `진행중` (docs/05-progress.md). 브랜치 `release-packaging`.

## 먼저 알아둘 것

- 이번 범위: 태그를 푸시하면 GitHub Actions가 배포 파일을 만들어 **GitHub Releases**에 올린다. 다운로드·설치·배포 방법은 `docs/07-release.md`.
  - Windows `*_x64-setup.exe`, macOS `*_universal.dmg`, Linux `*.deb`·`*.AppImage`, Android `clip-ferry-<버전>-android.apk`(배포 키로 서명)
- 범위 밖(후속): Windows 코드 서명, macOS 서명·공증, 자동 업데이트, 앱 기본 릴레이 주소.
- 이미 해 둔 것(Windows):
  - `npx tauri build` → `clip-ferry_0.1.0_x64-setup.exe`(3.4 MiB) 생성
  - 배포 키를 만들고(`%USERPROFILE%\.clip-ferry-release\`) 그 키로 `assembleRelease` → `apksigner`로 서명자 `CN=clip-ferry` 확인
- macOS·Linux 묶기와 CI의 Android 빌드는 이 PC에서 돌려 볼 수 없어 **첫 Release 실행에서 처음 확인**한다.
