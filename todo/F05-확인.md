## 참고

- 시작할 때마다 `FileSecretStore`는 개발 전용이라는 경고가 stderr에 나온다. 비밀이 `.cf-profiles/<이름>/secrets/` 에 평문 파일로 저장된다.
- 기기 이름은 `init`에서 정하고, 그룹은 `group create`로 따로 만든다(02-architecture의 API 스케치를 이에 맞게 고침).
- 비밀 저장소와 `state.bin` 중 한쪽만 남으면 열기를 거부한다(조용히 새로 만들지 않음). 프로필을 다시 만들려면 폴더를 지운다.
- `--relay`, `--profile`, `--profiles-dir`은 어느 서브커맨드 뒤에 써도 된다. 환경 변수 `CF_RELAY`, `CF_PROFILE`, `CF_PROFILES_DIR`도 된다.
