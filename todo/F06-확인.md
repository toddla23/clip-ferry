## 직접 확인할 것 (PowerShell, 터미널 3개)

터미널 0 (이전 확인 때 띄운 `cf`·릴레이가 남아 있으면 Ctrl+C로 닫는다):
`cargo run -p clip-ferry-relay -- --listen 127.0.0.1:8787`

터미널 A:

```
cargo run -q -p clip-ferry-cli -- --profile a init --name laptop
cargo run -q -p clip-ferry-cli -- --profile a group create
cargo run -q -p clip-ferry-cli -- --profile a invite
```

→ QR, `초대 코드: XXXX-XXXX-...`, 링크가 뜨고 기다린다.

터미널 B (`<코드>`는 A에 뜬 초대 코드를 그대로 붙여 넣는다):

```
cargo run -q -p clip-ferry-cli -- --profile b init --name phone-sim
cargo run -q -p clip-ferry-cli -- --profile b join <코드>
```

- [ ] A에 `참여 요청: phone-sim`과 6자리 `확인 숫자`, B에도 같은 6자리 숫자
- [ ] A에서 `y` 입력 → A에 `승인됨: phone-sim 추가됨`, B에 `joined`
- [ ] `--profile a status`, `--profile b status` → 둘 다 구성원 2명, 에포크 1, 릴레이 `connected`
- [ ] (선택) 코드를 소문자로 입력하거나 한 글자를 바꿔 입력 → 소문자는 통과, 바꾼 글자는 "체크 기호가 맞지 않습니다" 오류
- [ ] (선택) 새 초대(`--profile a invite`)에서 B와 다른 프로필(`--profile c init --name x` 후 `join`)로 해 보고 A에서 `n` → c에 "거절했거나 만료" 오류, A 구성원 수는 그대로
