### 3-4. SSH를 내 IP에만 잠깐 열기

1. VM 화면 → 왼쪽 **네트워킹**(네트워크 설정) → **인바운드 포트 규칙 추가**(포트 규칙 만들기 → 인바운드)
2. 원본: `내 IP 주소` / 서비스: `SSH` / 이름: `ssh-temp` → **추가**

PC(PowerShell):
```powershell
ssh -i "$env:USERPROFILE\.ssh\clipferry_azure" cf@<이름>
```
- 처음엔 `Are you sure you want to continue connecting` → `yes`
- [ ] `cf@clip-ferry:~$` 프롬프트가 뜬다

## 4. VM 기본 설정 (VM 안, 3-4의 SSH 창에서)

### 4-1. 업데이트·스왑 2GB·Docker

아래를 **한 번에** 붙여 넣는다 (몇 분 걸린다):
```bash
sudo apt-get update && sudo apt-get -y upgrade
sudo fallocate -l 2G /swapfile && sudo chmod 600 /swapfile && sudo mkswap /swapfile && sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker cf
free -h && docker --version
```
- [ ] `free -h`의 `Swap:` 줄이 `2.0Gi`
- [ ] `Docker version …`이 나온다
- `exit`로 나갔다가 3-4의 `ssh` 명령으로 다시 들어온다(docker 그룹 적용). `docker ps`가 권한 오류 없이 빈 표를 보여야 한다

### 4-2. Tailscale에 넣기

```bash
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up --ssh --hostname clip-ferry-azure
```
- 터미널에 나온 `https://login.tailscale.com/a/…` 주소를 PC 브라우저로 열어 **Pi·PC와 같은 Tailscale 계정**으로 승인한다
- [ ] `tailscale status`에 `clip-ferry-azure`와 Pi·PC가 보인다

### 4-3. SSH를 Tailscale로만 쓰고 인터넷 쪽은 닫기

PC(PowerShell, **새 창**):
```powershell
ssh cf@clip-ferry-azure
```
- `tailscale up --ssh`라 키 없이 Tailscale 계정으로 들어간다. 처음엔 브라우저 확인이 뜰 수 있다
- [ ] `cf@clip-ferry:~$`가 뜬다

들어가지면 포털에서 3-4의 `ssh-temp` 규칙을 **삭제**한다 (VM → 네트워킹 → 규칙 줄 오른쪽 `…` → 삭제).
- [ ] 인바운드 규칙에 22번이 없다
- [ ] PC에서 `ssh -i "$env:USERPROFILE\.ssh\clipferry_azure" cf@<이름>`이 **시간 초과로 실패**한다 (인터넷 쪽 SSH가 닫혔다)
