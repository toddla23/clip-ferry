### 3-4. SSH 열기

서버 관리 접속(SSH)은 어디서든(집 밖·Tailscale 밖) 들어갈 수 있게 연다. 대신 **비밀번호 로그인은 없고 3-1의 키로만** 들어간다(Azure 기본값, 4-2에서 확인). 인터넷의 자동 스캔이 로그에 계속 찍히는 것은 정상이고, 키가 없으면 들어올 수 없다. **개인키 파일(`clipferry_azure`)이 곧 서버 열쇠**이니 백업해 두고 남에게 주지 않는다.

1. VM 화면 → 왼쪽 **네트워킹**(네트워크 설정) → **인바운드 포트 규칙 추가**(포트 규칙 만들기 → 인바운드)
2. 원본: `Any` / 서비스: `SSH` / 이름: `ssh` → **추가** (위험 경고가 뜨면 확인하고 추가)

PC(PowerShell):
```powershell
ssh -i "$env:USERPROFILE\.ssh\clipferry_azure" jonghyeok@<이름>
```
- 처음엔 `Are you sure you want to continue connecting` → `yes`
- [ ] `jonghyeok@clip-ferry:~$` 프롬프트가 뜬다
- 키를 잃어버리면 포털의 VM → **암호 재설정**(Reset password)에서 새 공개키를 넣는다. 급할 때는 VM → **실행 명령**(Run command)으로 SSH 없이 명령을 돌릴 수 있다

## 4. VM 기본 설정 (VM 안, 3-4의 SSH 창에서)

### 4-1. 업데이트·스왑 2GB·Docker

아래를 **한 번에** 붙여 넣는다 (몇 분 걸린다):
```bash
sudo apt-get update && sudo apt-get -y upgrade
sudo fallocate -l 2G /swapfile && sudo chmod 600 /swapfile && sudo mkswap /swapfile && sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER
free -h && docker --version
```
- [ ] `free -h`의 `Swap:` 줄이 `2.0Gi`
- [ ] `Docker version …`이 나온다
- `exit`로 나갔다가 3-4의 `ssh` 명령으로 다시 들어온다(docker 그룹 적용). `docker ps`가 권한 오류 없이 빈 표를 보여야 한다

### 4-2. 비밀번호 로그인이 꺼져 있는지 확인

```bash
sudo sshd -T | grep -E '^(passwordauthentication|permitrootlogin)'
```
- [ ] `passwordauthentication no`, `permitrootlogin no` (또는 `without-password`)
