# F44. 계정 하나당 그룹 하나 — 확인할 것

상태: `완료` (PR #36) (docs/05-progress.md). 브랜치 `f44-one-group` (F43 완료 커밋 위).

이 문서만 보고 처음부터 끝까지 따라 할 수 있게 썼다. 각 단계는 **할 일 → 보여야 하는 것** 순서다. 다르게 보이면 맨 아래 "막히면"을 먼저 보고, 그래도 안 되면 그 화면·문구를 "시험 중 나온 것"에 적는다.

## 무엇을 시험하나

- 같은 계정의 두 번째 기기에는 `새 그룹 만들기`가 없고 `이 계정의 다른 기기로 연결`만 있다. 첫 기기에만 `새 그룹 만들기`가 있다.
- QR·코드 페어링 화면이 없다(데스크톱 `기기 추가`·`코드로 참여`, Android `QR로 참여`·`코드 입력으로 참여`). Android는 카메라 권한을 묻지 않는다.
- 승인해 줄 기기가 없을 때 `처음부터 다시 시작`으로 새 그룹을 만들 수 있고, 그러면 그 계정의 다른 기기는 다음에 켜질 때 예전 그룹에서 나온다.
- 앱 데이터 폴더만 지워진 PC가 창 없이 꺼지지 않고 물어본다.
- 서버를 올릴 때 계정 DB의 사용자·기기를 모두 지우고 모든 기기를 새로 시작한다(사용자 결정).

아래에서 "VM에서"는 `ssh -i "$env:USERPROFILE\.ssh\clipferry_azure" jonghyeok@clipferry.japaneast.cloudapp.azure.com`으로 들어간 창이다. 그 안에서 먼저 다음을 한 번 입력해 둔다.
```bash
cd ~/clip-ferry
C="docker compose --env-file deploy/.env.cloud -f deploy/compose.cloud.yml"
```

## 5. 처음부터 다시 시작 (기기를 잃은 척)
