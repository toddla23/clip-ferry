# F18. Android 보내기: 빠른 설정 타일 · 알림 버튼 — 확인할 것

상태: `진행중` (docs/05-progress.md). 브랜치 `f18-android-send` (F17 브랜치 위). 실기기 확인 전이다.

## 먼저 알아둘 것

- 이번 범위: 폰에서 복사한 **텍스트·이미지를 1탭으로 다른 기기에 보낸다**.
  - 빠른 설정 타일 `클립보드 보내기`
  - 상시 알림의 `클립보드 보내기` 버튼
  - 앱 화면의 `지금 클립보드 보내기` 버튼(시험용)
- 왜 화면이 잠깐 열리나: 안드로이드 10부터는 **화면에 초점이 있는 앱만 클립보드를 읽을 수 있다.**
  - 그래서 타일·알림 버튼은 보이지 않는 화면을 띄운다. 초점을 받는 순간 클립보드를 읽고 바로 닫는다.
  - 전환 효과를 껐으므로 깜빡임 없이 원래 앱으로 돌아와야 한다.
- 결과는 토스트로 알린다. 예: `텍스트를 다른 기기 1대로 보냈습니다`, `보냈지만 지금 연결된 다른 기기가 없습니다`.
- 보내지 않는 경우(토스트로 알림):
  - 클립보드가 비어 있음
  - 다른 기기에서 받아 이 앱이 넣은 내용(그룹이 이미 갖고 있다)
  - 민감한 내용으로 표시된 복사 + `민감한 내용도 보내기`가 꺼져 있음(기본은 켜짐, 데스크톱 `sync_sensitive`와 같은 뜻)
  - 이미지를 읽을 권한이 없음(복사한 앱이 다른 앱에 열어 주지 않음). 앱이 죽지 않는다
  - 이미지가 20 MiB 초과
- 이미지는 PNG·JPEG·GIF·WebP를 그대로 보내고, 다른 형식(HEIC 등)은 JPEG로 바꿔 보낸다.
- 연결이 꺼져 있으면(서비스 중지 등) 보내기를 누를 때 연결을 켜고 최대 8초 기다린 뒤 보낸다.
- 이미 해 둔 것(Windows):
  - FFI 테스트 12개 통과. 새 테스트는 실제 릴레이로 폰 → PC 텍스트·이미지, 연결 전·빈 텍스트·1 MiB 초과·모르는 이미지 형식·연결 끊긴 뒤 오류를 본다.
  - `.so`와 Kotlin 바인딩을 만들었고 `assembleDebug`가 성공했다(경고 없음).

## 0. 준비

- 폰: USB 연결, **Tailscale 켜기**. PC: `pc1` 데스크톱 앱이 `연결됨`이고 폰과 같은 그룹.

## 1. 빌드·설치 (PC, PowerShell)

```powershell
cd C:\Users\jonghyeok\Documents\clip-ferry
git checkout f18-android-send
.\scripts\build-android-core.ps1
cd apps\android
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
.\gradlew.bat installDebug
cd ..\..
```

- [ ] `installDebug`가 `BUILD SUCCESSFUL`이다
- [ ] 앱 메인 화면에 `보내기` 카드가 있다(`타일 추가`(안드로이드 13+), `지금 클립보드 보내기`, `민감한 내용도 보내기` 켜짐)
- [ ] 상시 알림을 펼치면 `클립보드 보내기`와 `중지` 버튼이 있다

## 2. 타일 추가

- [ ] `타일 추가`를 누르면 시스템 팝업이 뜨고, 추가하면 `타일을 추가했습니다`
  - 버튼이 없으면(안드로이드 12 이하) 빠른 설정 패널 → 편집(연필) → `클립보드 보내기`를 끌어다 놓는다
- [ ] 빠른 설정에 `클립보드 보내기` 타일이 보이고, 아래 작은 글씨가 `연결됨`이다

## 3. 텍스트 — 타일 / 알림 버튼 (완료 조건 1)

1. 브라우저나 메모 앱에서 텍스트를 복사한다.
2. 빠른 설정을 내려 `클립보드 보내기` 타일을 누른다.

- [ ] 패널이 닫히고 **깜빡임 없이** 원래 앱이 그대로 보인다(완료 조건 2)
- [ ] `텍스트를 다른 기기 1대로 보냈습니다` 토스트
- [ ] PC에서 Ctrl+V → 같은 글(한글·이모지·여러 줄 포함)

3. 다른 텍스트를 복사하고 알림창을 내려 상시 알림의 `클립보드 보내기`를 누른다.

- [ ] 같은 결과(토스트, PC 붙여넣기, 깜빡임 없음)

## 4. 이미지 — 타일 / 알림 버튼 (완료 조건 1)

1. 갤러리(삼성 갤러리·Google 포토)에서 사진을 열고 `복사`(공유 메뉴나 ⋮ 메뉴에 있는 경우)를 누른다.
   - `복사`가 없으면: 브라우저에서 이미지를 길게 눌러 `이미지 복사`, 또는 스크린샷 후 미리보기의 `복사`
2. 타일을 누른다.

- [ ] `이미지를 다른 기기 1대로 보냈습니다` 토스트
- [ ] PC 그림판·채팅 앱에 붙여넣으면 같은 이미지
- [ ] 알림 버튼으로도 한 번 더(다른 이미지)
- [ ] 사진 원본이 큰 경우(수 MB) 몇 초 안에 간다

## 5. 보내지 않는 경우 (완료 조건 3 포함)

- [ ] PC에서 텍스트를 복사해 폰이 받은 직후 타일을 누르면 `다른 기기에서 받은 내용이라 다시 보내지 않았습니다`
- [ ] 이미지를 읽을 수 없는 경우 `이미지를 읽을 수 없습니다…` 토스트, 앱이 죽지 않는다
  - 일부 앱(예: 메신저 내부 이미지)의 `복사`가 이렇게 될 수 있다. 되는 앱·안 되는 앱 이름을 알려 달라. 재현이 안 되면 건너뛴다
- [ ] (선택) 비밀번호 관리자에서 비밀번호를 복사하고 `민감한 내용도 보내기`를 끈 채 타일 → `민감한 내용으로 표시된 복사라 보내지 않았습니다`. 켜면 보내진다. 시험 후 원래대로 둔다
- [ ] 알림의 `중지`로 연결을 끈 뒤 텍스트를 복사하고 타일 → 연결이 다시 켜지고(상시 알림이 다시 뜸) 몇 초 안에 `보냈습니다`

## 6. 그 밖의 경우

- [ ] PC 앱을 끈 상태에서 보내면 `보냈지만 지금 연결된 다른 기기가 없습니다`
- [ ] 폰 화면 잠금 상태에서 타일을 누르면 잠금 해제를 요청하고, 풀면 보낸다
- [ ] 앱 화면의 `지금 클립보드 보내기`도 같은 결과

## 알려진 사항 (이번 범위 밖)
