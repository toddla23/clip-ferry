# F11. 텍스트 자동 동기화 (데스크톱) — 확인할 것

상태: `확인대기` (docs/05-progress.md)

## 먼저 알아둘 것

- 이제 **복사만 하면 자동으로** 그룹의 다른 기기로 간다. 앱이 그룹에 연결돼 있는 동안만 클립보드를 읽는다(마법사 중, 연결 전, 그룹이 없을 때는 읽지 않는다).
- **앱을 켜기 전부터 클립보드에 있던 내용은 보내지 않는다.** 켠 뒤에 새로 복사한 것만 간다.
- 받은 텍스트는 클립보드에 바로 써진다(디스크·화면에는 남기지 않는다).
- **에코 방지**: 마지막으로 보냈거나 받아서 쓴 내용의 해시(내용 자체는 안 쥠)와 같으면 보내지 않는다. 그래서 받은 내용이 되돌아가 무한 반복되지 않는다. 같은 내용을 연속으로 두 번 복사해도 한 번만 간다. 보내기에 실패하면 기록을 지워, 다시 복사하면 보내진다.
- **연속 복사 묶기**: 클립보드가 바뀐 뒤 300 ms 동안 조용해지면 그때 읽는다. 빠르게 a, b, c를 복사하면 c만 간다.
- **민감 항목 제외**(Windows): `ExcludeClipboardContentFromMonitorProcessing` 이 있거나, `CanIncludeInClipboardHistory` 값이 0이면 보내지 않고 **내용을 읽지도 않는다.** 설계 문서의 두 가지에 더해 **`Clipboard Viewer Ignore`**(KeePass 계열이 쓴다)와 **`CanUploadToCloudClipboard`=0** 도 제외한다. macOS는 `org.nspasteboard.ConcealedType`·`TransientType`을 제외한다(코드는 있으나 실행 못 해 봄).
- 크기: 비어 있거나 1 MiB(UTF-8)를 넘는 텍스트는 보내지 않는다. 이때 알림은 없다(트레이 알림은 이미지와 함께 F12).
- **설계 문서와 다른 점**: 변경 감지를 Windows `AddClipboardFormatListener`(숨은 창과 메시지 루프가 필요) 대신 **`GetClipboardSequenceNumber`를 250 ms마다 확인**하는 방식으로 했다. 값이 바뀌었는지만 보므로 비용이 거의 없고, 결과(복사 후 약 0.3~0.6초에 감지)는 같다. macOS는 문서대로 `changeCount` 폴링(250 ms).
- 일시정지·보내기/받기 끄기 설정은 F13에서 만든다. 지금은 켜져 있는 동안 항상 동작한다.

## 직접 확인할 것 (PowerShell)

사전 준비: 릴레이 한 개, 데스크톱 앱 한 개(프로필 `pc1` 등)를 F10 확인 방법대로 띄워 그룹을 만들고, CLI 기기를 하나 페어링한다.

```powershell
# 릴레이 (터미널 A)
cargo run -p clip-ferry-relay -- --listen 127.0.0.1:8787
# 데스크톱 앱 (터미널 B, 저장소 루트에서)
$env:CF_DESKTOP_PROFILE="pc1"; cd apps\desktop; npm run tauri dev
# CLI 기기 (터미널 C, 저장소 루트에서). 앱에서 `기기 추가`를 눌러 코드를 얻고:
cargo run -q -p clip-ferry-cli -- --profile x init --name cli-x
cargo run -q -p clip-ferry-cli -- --profile x join <코드>     # 앱에서 숫자 비교 후 승인
cargo run -q -p clip-ferry-cli -- --profile x listen
```

1. [ ] 메모장에서 글자를 복사(Ctrl+C) → 터미널 C에 `[앱의 기기 이름] 복사한 글자`가 1초쯤 안에 뜬다
2. [ ] 다른 터미널에서 `cargo run -q -p clip-ferry-cli -- --profile x send "cli에서 왔음"` → 메모장에 Ctrl+V 하면 그 글자가 붙는다
3. [ ] 2번 뒤 터미널 C(`listen`)에 같은 글자가 **다시 뜨지 않는다**(되돌아오지 않음)
4. [ ] 비밀번호 관리자(1Password / Bitwarden / KeePassXC 중 하나)에서 비밀번호를 복사 → 터미널 C에 **아무것도 안 뜬다**. 이어서 메모장에서 일반 글자를 복사하면 정상적으로 뜬다
5. [ ] 반대 방향, 두 번째 데스크톱 앱(프로필 `pc2`, F10 확인 방법 참고)과 페어링해서 A에서 복사 → B에서 붙여넣기, B에서 복사 → A에서 붙여넣기. 둘이 주고받아도 무한 반복되지 않는다(몇 초 지켜본다)

정리(선택): F10 확인 문서의 정리 방법과 같다.

- 구조: `apps/desktop/src-tauri/src/clipsync.rs`(감시·에코 방지·디바운스, 플랫폼 몰라도 되는 부분, 가짜 클립보드로 시험) / `sysclip.rs`(Windows·macOS 클립보드 구현). `shell.rs`는 받은 텍스트를 `write_received`로 넘기고, 복사된 텍스트를 세션의 `send_text`로 보내기만 한다. 암호·프로토콜 로직은 없다.
